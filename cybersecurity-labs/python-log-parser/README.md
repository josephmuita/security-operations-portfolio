# Python Log Parser Lab

## Objective
Demonstrate log analysis using Python to detect failed login attempts.

## Scenario
A simulated authentication log was analyzed to identify repeated failed login attempts that may indicate brute-force activity.

## Tools Used
- Python

## Skills Demonstrated
- Reading log files
- Parsing text data
- Counting security events
- Identifying repeated login failures

## Results
- Total Failed Login Attempts: 4
- Most Targeted Account: admin (3 attempts)

## Security Insight
Repeated failed login attempts against a single account may indicate:
- Brute-force attack attempts
- Credential guessing
- Unauthorized access attempts
