# Basic Network Troubleshooting Lab

## Objective
Demonstrate basic network connectivity troubleshooting skills.

## Tools Used
- Command Prompt / Terminal
- Ping utility
- DNS resolution checks

## Scenario
Network connectivity was tested by verifying communication between the local machine and external websites.

## Method

1. Open Command Prompt.
2. Test connectivity using ping command.
3. Verify DNS resolution.
4. Observe response results.

## Commands Used

- ping google.com
- ipconfig /all
- nslookup google.com

## Security / IT Insight

Network troubleshooting is important for IT support roles to diagnose connectivity problems quickly.
